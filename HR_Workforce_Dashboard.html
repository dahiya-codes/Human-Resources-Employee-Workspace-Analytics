SQL Architecture — How the Burnout Index Works
CASE WHEN logic translated to visual spec
-- Burnout Index SQL (Simplified)
CASE WHEN overtime = 'Yes' THEN 3 -- max weight
+ (4 - work_life_balance) -- 0-3 pts
+ (4 - job_satisfaction) -- 0-3 pts
+ (4 - env_satisfaction) -- 0-3 pts
+ promotion_stagnation -- 0-2 pts
+ pay_gap_score -- 0-2 pts
+ business_travel -- 0-2 pts
+ low_involvement -- 0-1 pt
Total Max = 18 points
